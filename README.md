# Head First Design Patterns 學習筆記

用自己的話寫筆記,用程式碼證明自己懂。

## 學習原則

1. 不抄書:每個 pattern 用自己的話解釋
2. 先照書寫一次範例,再用**自己的情境**改寫一次
3. 一定要寫「什麼時候不該用」
4. 每讀完一章就 commit
